Use this form to collect inputs before running a full ASO keyword recommendation.

```text

产品差异点：

投放目标：
预算：
目标CPA：

历史ASA数据：有 / 无
搜索词报告：有 / 无
竞品ASO词表：有 / 无
自身ASO词表：有 / 无
点点数据热度：有 / 无

竞品名单：
当前标题：
当前副标题：
当前关键词字段：
截图是否本地化：是 / 否

需要输出：
- 3词推荐 / 多词推荐 / ASA结构 / 飞书文档
```

## Minimum viable input

If the user cannot provide everything, collect at least:
- App name
- App ID or App Store URL
- target country
- core functions
- main objective
- budget
- target CPA if used

## Better analysis input

Ask for these next if available:
- self ASO keyword sheet
- competitor ASO keyword sheet
- ASA campaign export
- search term report
- competitor list
